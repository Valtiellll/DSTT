Để commit và push to git

vscode:

git init (tạo repo local trống để up lên repo git cloud)

git remote add origin https://github.com/Valtiellll/DSTT.git (add source để đẩy code từ repo local vào reop cloud)

git add . (gói gọn lại những file code vào để chuẩn bị gửi đi)

git commit -m "Initial commit" (tạo checkpoint code để chuẩn bị gửi)

git push -u origin main (push lên nhánh chính của git repo, lệnh -u sẽ nói vscode luôn luôn đẩy code lên nhánh repo này nên mốt ae xài git push là dc)
